🔧 TROUBLESHOOTING

Problem: "No textures loaded" warning
Solution: Run: python download_textures.py --quick

Problem: Low frame rate
Solution: Reduce anti-aliasing in PandaUniverse.py:
          Change "multisamples 4" to "multisamples 2"

Problem: Import errors
Solution: pip install -r requirements.txt

Problem: Black screen
Solution: Update graphics drivers, restart terminal

💡 PRO TIPS

  1. Download textures FIRST for best quality:
     python download_textures.py

  2. Use --quick for faster texture download:
     python download_textures.py --quick

  3. Run in fullscreen by editing PandaUniverse.py:
     fullscreen 1

  4. Adjust black hole mass in main.py:
     BlackHoleEngine(mass=10, ...)  # Change 10 to any value

  5. Add more planets by editing create_celestial_bodies()
     in PandaUniverse.py
