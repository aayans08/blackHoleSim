**wgpu changes since 0.19 that the existing `src/main.rs` (927 lines) will hit:**
- **0.20:** a `compilation_options` field on vertex, fragment and compute stages.
- **22:** a `cache: None` field on pipeline descriptors; `memory_hints` on `DeviceDescriptor`.
- **23:** `entry_point` became `Option<&str>`; `set_bind_group` takes an `Option`.
- **24:** passes enforce lifetimes; `.forget_lifetime()` gives a `'static` pass, which egui needs.
- **Renames (seen in the v30 source):** `ImageCopyTexture` → `TexelCopyTextureInfo`, `ImageDataLayout` → `TexelCopyBufferLayout`. These affect main.rs:575 and :582.
- **25:**
  - `request_adapter` returns `Result` instead of `Option`.
  - `request_device(&desc)` takes one argument; tracing moved to `DeviceDescriptor.trace`.
  - `Maintain` became `PollType`, and `poll` now returns a `Result`.
- **27:** `experimental_features` field on `DeviceDescriptor`; experimental features need `unsafe` to enable; `PollType::Wait` takes a timeout.
- **28:**
  - Push constants are now "immediates": `immediate_size` on `PipelineLayoutDescriptor`, `set_immediates`, `var<immediate>`.
  - `MipmapFilterMode` is its own enum.
  - `multiview` became `multiview_mask`.
  - `enumerate_adapters` is async.
  - `push_error_scope()` returns a guard; call `.pop().await` on it.
- **29:**
  - `get_current_texture()` returns a `CurrentSurfaceTexture` enum, and `SurfaceError` is gone (main.rs:727, :911).
  - `InstanceDescriptor` has no `Default`. Use `new_with_display_handle(Box::new(event_loop.owned_display_handle()))` or `new_without_display_handle()`.
  - `Instance::new` takes the descriptor by value.
  - `bind_group_layouts` is `&[Option<&BindGroupLayout>]`.
  - `DepthStencilState.depth_write_enabled` and `depth_compare` are `Option`s.
  - Mapped writes go through `WriteOnly<[u8]>`.
- **30:**
  - `queue.present(frame)` replaces `frame.present()` (main.rs:779).
  - New `SurfaceConfiguration.color_space` field (use `SurfaceColorSpace::Auto`; HDR/EDR is possible on Metal).
  - `VertexState.buffers` is `&[Option<VertexBufferLayout>]`.
  - Integer varyings need an explicit `@interpolate(flat)`.
  - `get_mapped_range` returns a `Result`.
  - New `RequestAdapterOptions.apply_limit_buckets` field.

**winit 0.29 → 0.30:**
- `EventLoop::run(closure)` (main.rs:886) is replaced by `run_app(&mut impl ApplicationHandler)`, with `resumed`, `window_event`, `device_event` and `about_to_wait` methods.
- `WindowBuilder` (main.rs:10) is removed. Use `Window::default_attributes()` and `ActiveEventLoop::create_window` inside `resumed()`.
- Keep the window as `Arc<Window>` so the surface is `wgpu::Surface<'static>`.
- The `KeyCode` / `PhysicalKey` keyboard code is unchanged.
- For free-flight mouse look, use `DeviceEvent::MouseMotion` with `set_cursor_grab(CursorGrabMode::Locked)`. `Confined` is not supported on macOS.

**egui 0.37 pitfalls (both confirmed on this machine):**
- egui now has **no default features**. Without `features = ["default_fonts"]` it logs "No font provider… No text will be visible".
- `Context::run` is gone. Use `ctx.run_ui(raw, |ui| …)` or `run_pass(raw, |ctx| …)`.
- `textures_delta.set` is a `HashMap<TextureId, SmallVec<[ImageDelta; 1]>>`. Dropping a `TexturesDelta` without applying it triggers a debug panic, so drain both `set` and `free`.

**Skeleton excerpts** (wgpu 30.0.2 / winit 0.30.13 / egui 0.37.0; see main.rs for the full file):
```rust
// main(): instance needs the display handle (v29+), by value
let event_loop = EventLoop::new()?; event_loop.set_control_flow(ControlFlow::Poll);
let mut desc = wgpu::InstanceDescriptor::new_with_display_handle(Box::new(event_loop.owned_display_handle()));
desc.backends = wgpu::Backends::METAL;
let instance = wgpu::Instance::new(desc);
event_loop.run_app(&mut App { instance, gfx: None })?;

// ApplicationHandler
impl ApplicationHandler for App {
  fn resumed(&mut self, el: &ActiveEventLoop) {
    if self.gfx.is_some() { return; }
    let window = Arc::new(el.create_window(Window::default_attributes().with_title("Universe")).unwrap());
    self.gfx = Some(pollster::block_on(Gfx::new(window, &self.instance)));
  }
  fn window_event(&mut self, el: &ActiveEventLoop, _: WindowId, ev: WindowEvent) {
    let Some(g) = self.gfx.as_mut() else { return };
    if g.egui_state.on_window_event(&g.window, &ev).consumed { return; }
    match ev { WindowEvent::CloseRequested => el.exit(),
               WindowEvent::Resized(s) => g.resize(s.width, s.height),
               WindowEvent::RedrawRequested => g.render(), _ => {} }
  }
  fn about_to_wait(&mut self, _: &ActiveEventLoop) { if let Some(g) = &self.gfx { g.window.request_redraw(); } }
}

// Gfx::new
let surface = instance.create_surface(window.clone())?;               // Surface<'static>
let adapter = instance.request_adapter(&wgpu::RequestAdapterOptions {
    power_preference: wgpu::PowerPreference::HighPerformance, force_fallback_adapter: false,
    compatible_surface: Some(&surface), apply_limit_buckets: false }).await?;   // Result
let wanted = wgpu::Features::SHADER_F16 | wgpu::Features::FLOAT32_FILTERABLE | wgpu::Features::TIMESTAMP_QUERY;
let (device, queue) = adapter.request_device(&wgpu::DeviceDescriptor {
    label: None, required_features: adapter.features() & wanted,
    required_limits: adapter.limits(),          // otherwise you get WebGPU defaults (256 MiB buffers, 4 storage tex)
    experimental_features: wgpu::ExperimentalFeatures::disabled(),
    memory_hints: wgpu::MemoryHints::Performance, trace: wgpu::Trace::Off }).await?;
let config = wgpu::SurfaceConfiguration { usage: wgpu::TextureUsages::RENDER_ATTACHMENT, format /*first is_srgb()*/,
    color_space: wgpu::SurfaceColorSpace::Auto, width, height, present_mode: wgpu::PresentMode::AutoVsync,
    desired_maximum_frame_latency: 2, alpha_mode: caps.alpha_modes[0], view_formats: vec![] };
// layouts: bind_group_layouts: &[Some(&bgl)], immediate_size: 0
// compute pipeline: entry_point: Some("cs_main"), compilation_options: Default::default(), cache: None
// storage texture BGL entry: StorageTexture { access: WriteOnly, format: Rgba16Float, view_dimension: D2 }
// render pipeline: buffers: &[], multiview_mask: None, cache: None; sampler mipmap_filter: wgpu::MipmapFilterMode::Nearest
let egui_state = egui_winit::State::new(egui_ctx.clone(), egui::ViewportId::ROOT, &window,
    Some(window.scale_factor() as f32), window.theme(), Some(device.limits().max_texture_dimension_2d as usize));
let egui_renderer = egui_wgpu::Renderer::new(&device, format, egui_wgpu::RendererOptions::default());

// render()
let frame = match surface.get_current_texture() {
    wgpu::CurrentSurfaceTexture::Success(f) => f,
    wgpu::CurrentSurfaceTexture::Suboptimal(_) | wgpu::CurrentSurfaceTexture::Outdated
    | wgpu::CurrentSurfaceTexture::Lost => { surface.configure(&device, &config); return; }
    _ => return };                                                   // Timeout / Occluded / Validation
let mut out = egui_ctx.run_ui(egui_state.take_egui_input(&window), |ui| {
    egui::Window::new("HUD").show(ui.ctx(), |ui| { ui.label("…"); }); });
egui_state.handle_platform_output(&window, std::mem::take(&mut out.platform_output));
let jobs = egui_ctx.tessellate(std::mem::take(&mut out.shapes), out.pixels_per_point);
let screen = egui_wgpu::ScreenDescriptor { size_in_pixels: [w, h], pixels_per_point: out.pixels_per_point };
for (id, ds) in out.textures_delta.set.drain() { for d in &ds { egui_renderer.update_texture(&device, &queue, id, d); } }
let egui_cmds = egui_renderer.update_buffers(&device, &queue, &mut encoder, &jobs, &screen);
{ let mut c = encoder.begin_compute_pass(&wgpu::ComputePassDescriptor { label: None, timestamp_writes: None });
  c.set_pipeline(&compute); c.set_bind_group(0, &compute_bg, &[]); c.dispatch_workgroups(w.div_ceil(8), h.div_ceil(8), 1); }
{ let mut r = encoder.begin_render_pass(&wgpu::RenderPassDescriptor { label: None,
      color_attachments: &[Some(wgpu::RenderPassColorAttachment { view: &view, depth_slice: None, resolve_target: None,
          ops: wgpu::Operations { load: wgpu::LoadOp::Clear(wgpu::Color::BLACK), store: wgpu::StoreOp::Store } })],
      depth_stencil_attachment: None, timestamp_writes: None, occlusion_query_set: None, multiview_mask: None })
    .forget_lifetime();                                             // egui wants RenderPass<'static>
  r.set_pipeline(&blit); r.set_bind_group(0, &blit_bg, &[]); r.draw(0..3, 0..1);  // samples the Rgba16Float texture
  egui_renderer.render(&mut r, &jobs, &screen); }
for id in out.textures_delta.free.drain() { egui_renderer.free_texture(&id); }
queue.submit(egui_cmds.into_iter().chain(std::iter::once(encoder.finish())));
window.pre_present_notify(); queue.present(frame);
```
The WGSL compute shader writes with `textureStore(hdr_out, gid.xy, …)` to `texture_storage_2d<rgba16float, write>`. The blit pass samples that texture with a filtering sampler, applies Reinhard tone mapping, and lets the sRGB surface handle gamma. When the window is resized, rebuild the HDR texture and bind groups using `pipeline.get_bind_group_layout(0)`.

## 2. Metal limits on this Apple M3 (wgpu 30.0.2, `adapter.limits()` / `features()`)

The value in brackets is wgpu's WebGPU default, which you get if you don't request the adapter's limits.

**Buffers and bindings**
- `max_buffer_size`: 4 GiB−1 [256 MiB]
- `max_storage_buffer_binding_size`: ~4 GiB [128 MiB]
- `max_uniform_buffer_binding_size`: 4 GiB [64 KiB]
- Storage, uniform and vertex buffers plus acceleration structures share **29 slots** per shader stage (Metal's buffer argument table).
- `max_storage_textures_per_shader_stage`: **32** [4]
- Sampled textures per stage: 96. Samplers per stage: 16. Bind groups: 8 [4].
- Bindless arrays (`TEXTURE_BINDING_ARRAY`): supported.

**Compute and textures**
- Workgroup shared storage: 32 KiB [16 KiB]
- Invocations per workgroup: 1024 [256]
- Workgroups per dimension: 65535
- Max texture size: 2D 16384, 3D 2048
- Immediates: 256 bytes (`IMMEDIATES` feature)

**Shader number types**
- **f64 is not available.** `SHADER_F64` is false, and naga rejects WGSL `f64` with "requires the FLOAT64 capability".
  - Keep world positions in f64 on the CPU (glam `DVec3` and `dcamera`).
  - Send camera-relative f32 to the GPU (floating origin).
  - Use an infinite reverse-Z projection.
  - Emulate f64 as two f32s ("double-single") only where you really need it.
- `SHADER_F16` works with `enable f16;` (tested).
- `SHADER_I16`, `SHADER_INT64`, `SUBGROUP` (reported subgroup size 4–64), `SHADER_FLOAT32_ATOMIC` and `TEXTURE_ATOMIC` are all supported.

**Texture formats**
- `FLOAT32_FILTERABLE` and `FLOAT32_BLENDABLE` are supported but must be requested. Without them, `Rgba32Float` can't be filtered.
- Rgba16Float, Rgba32Float, R32Float and Rgba8Unorm support read-write storage. Rg11b10Ufloat and Bgra8Unorm are read-only or write-only. Read-write storage for these formats needs `TEXTURE_ADAPTER_SPECIFIC_FORMAT_FEATURES`; core WebGPU only allows it for r32 formats.
- BC, ASTC and ETC2 texture compression are all supported. `RG11B10UFLOAT_RENDERABLE` is supported.

**Timestamps**
- `TIMESTAMP_QUERY` is true, but `TIMESTAMP_QUERY_INSIDE_PASSES` and `TIMESTAMP_QUERY_INSIDE_ENCODERS` are **false**. You can only time whole passes via `timestamp_writes` on the pass descriptors.
- The timestamp period is 1 ns. wgpu-profiler 0.28 handles this setup.

**Not available:** `EXPERIMENTAL_RAY_QUERY` and `PIPELINE_CACHE`.

**Recommendations**
1. **Use one shared target dir.** Set `CARGO_TARGET_DIR=$HOME/.cargo/shared-target`, or put `[build] target-dir = "/Users/aayan/.cargo/shared-target"` in `~/.cargo/config.toml`. All worktrees then reuse the compiled dependencies instead of using 0.6–1.4 GB each.
   - Builds from different worktrees will wait for each other on the build lock. That is safe.
   - They also overwrite the same `target/debug/<bin>`, so run the binary straight after building.
   - Avoid `--all-targets` and `cargo test` builds unless needed, because they compile the crate a second time.
2. **Use this dev profile.** Debug info on dependencies is the biggest cost (1.4 GB → 0.75 GB). Optimised dependencies also make wgpu, naga and egui fast at runtime.
   ```toml
   [profile.dev]
   debug = "line-tables-only"
   incremental = false   # minor saving: only the main crate's incremental dir (~13 MB here); keep true if edit-loop speed matters
   [profile.dev.package."*"]
   opt-level = 2
   debug = false
   [profile.release]
   lto = "thin"
   codegen-units = 16
   strip = true          # thin LTO: about half the link time of fat LTO for ~1 MB more binary
   ```
3. **Leave `split-debuginfo` at its macOS default**, which is "unpacked" with no `.dSYM`. That is already the smallest; "packed" adds `.dSYM` copies.
4. **Build release only to measure performance.** Use dev with optimised dependencies day to day.
5. **Cleanup commands:**
   - `cargo clean --workspace` keeps the dependencies.
   - `cargo clean -r` removes release output only.
   - `rm -rf <target>/debug/incremental`.
   - `~/.cargo/registry/src` (482 MB) can be deleted safely; cargo re-extracts it from `cache/` when needed.
   - `build.build-dir` is stable in this cargo (verified), but it only moves intermediate files elsewhere; it doesn't save space.

All test build directories I created have been deleted; the scratch folder is about 13 MB.
