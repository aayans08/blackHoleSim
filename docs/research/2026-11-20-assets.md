**Totals**
- The folder is 7.0 MB (`du`), but only 7 files are unique: 4,562,347 B (about 4.4 MiB).
- The 5 duplicates take 2,757,931 B.

**Findings**
- **The `_4k` names are wrong.** `download_textures.py:78-82,95,108,121,161` fetch `.../download/2k_*.jpg` and save them as `*_4k.jpg`, so every "4k" file is really 2k. The script's "NASA Blue Marble 8K / LRO / SDO" labels (`download_textures.py:9-13,70-72,104,117,130`) are also inaccurate: every URL points to solarsystemscope.com.
- **Several referenced files are missing.** `PandaUniverse.py:183-193` expects `earth_normal_4k`, `earth_specular_4k`, `moon_4k`, `mars_4k`, `jupiter_4k`, `saturn_4k` and `saturn_rings_4k`, and none of them are under `planets/`.
- **The HDRI is gone.** `FINAL_SOLUTION.md:153` claims `textures/hdri/rogland_night_4k.exr` (93 MB, Poly Haven), and `RealisticBlackHoleRenderer.py:74` loads it, but `hdri/` is empty. That HDRI was a ground-based night sky with a horizon, so it is unsuitable for space anyway.
- **The Rust renderer loads no texture files at all.**
  - `src/main.rs:277-278` builds a procedural starfield. `create_starfield` (`src/main.rs:523-570`) makes a 2048×**2048** RGBA8 image with `mip_level_count: 1` (`src/main.rs:566`). That square image is sampled as a 2:1 equirect at LOD 0 (`shaders/compute.wgsl:190-200`), so it gets stretched and aliased.
  - Its RNG `(*s / 65536) as f32 / 32768.0` (`src/main.rs:539-542`) returns values in [0, 2). About ¾ of the 50k stars land out of bounds and are dropped (`src/main.rs:550`).
  - This setup is the direct cause of the "pixelated" look the owner rejects.
- `texture_manager.py` is a ModernGL Python loader with no URLs (`texture_manager.py:24,42`). It is legacy and irrelevant to Rust.

**Usability for a high-end renderer**
- **None of the files meet the bar.** Planets need equirect maps of at least 4k, and everything here is 2048×1024.
- **Sky files: do not use.** `stars_milky_way.jpg` / `starfield_4k.jpg` is a 2k photo skybox at about 10.5′ per pixel, so stars render as blobs. Replace it with catalogue stars plus a procedural galaxy.
- **Sun: use procedural.** Granulation, limb darkening and corona will look better than a 2k photo.
- **Keep the 7 unique files only as low-LOD or dev placeholders.** Delete the 5 duplicates and `.DS_Store` when the cleanup phase is allowed. I did not touch them.

**`.gitignore`** is a single line, `/target`.
- `target/` is ignored.
- `venv/`, `__pycache__/`, `.DS_Store`, `textures/` and any future data cache are **not** ignored, so a `git add .` would commit them.

**`.gitattributes`** contains only `* text=auto`.
- There are no LFS rules and no `binary`/`-diff` entries. Git still auto-detects JPEGs as binary.
- Any multi-MB catalogue or EXR committed later would go raw into history.

**Recommendation:**
- Ignore a `/data/cache/` raw-download folder.
- Keep a checked-in fetch manifest with URL, SHA-256 and licence for each file.
- Commit only small preprocessed outputs, or use LFS.
